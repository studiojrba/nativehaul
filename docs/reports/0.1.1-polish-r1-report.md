## Calls I made
- **Welcome trust beat:** "A few things worth knowing: I only ask for what I actually need, nothing extra." / "And you're in full control the whole way." I checked that this is true in the build: the app has no entitlements beyond the hardened runtime, and no code path asks for Accessibility, Full Disk Access, Input Monitoring, Screen Recording or Apple Events. The only system prompts it can trigger are Keychain access for its own items and the removable-volume prompt when your games folder is on an external drive.
- **nxnative line:** "I use your own copy on this Mac. I never bundle it, repackage it or download it from anywhere else." nativehaul doesn't fetch nxnative (ADR 0027). No nxnative checkout exists on this Mac, and no upstream URL is recorded in the repo, so I couldn't truthfully name "the author's official GitHub".
- **Good to know wording:** "a new area or effect can hitch for a moment the first time your Mac shows it … usually only happens the first time". I couldn't check what nxnative's shader step does, so the copy promises no cache and no pre-warm.
- **Emulator offers:** only the existing catalog (official GitHub releases for melonDS and PCSX2, the official pinned hosts for RetroArch and Dolphin). The card says "official sources", not "GitHub", because two of the four aren't on GitHub. RetroArch and Dolphin are the recommended pre-ticks.
- **Tutorial illustrations never pin made-up files on your real games.** The "Files found together" card shows "For example · Your game" unless the scan found a real grouped game. The demo build's log says "Sorting the base game, updates and DLC".
- **Bring a friend title:** "Pass the other controller" instead of "Joy-Con", to keep a Nintendo trademark out of the UI.
- **Shelf membership:** Cosy and Bring a friend match words in a game's genres and tags. Brand new means a release in the last 2 years. Fresh means added in the last 30 days. Suggestions share a genre with your top 3 Jump Back In games.
- **Build log narration:** one plain line per engine stage. Warnings and failures are said. Progress beats are dropped. Unknown steps read "Working on {name}". The raw log is still under the build's tools.
- **Music during onboarding** now uses the same settled loop and settings as the shell. Make's ambience and tick files were ignored.
- **Batch 4:** Settings, Detail and Builds tokens already matched Make 1:1 from 0.1.0. The remaining Make diffs (Player One/Two, Pre-build shaders, Pause builds, the "Library file" label, enable toggles) conflict with this round's rules, so I didn't apply them.

## Needs your eyes
- **Wording approval:** "library key" throughout, and "Game ID" on Detail and preflight.
- **Settings → Directories → Library key** still shows the real path (for example `~/Switch/ProdKeys.NET-v22.5.0/prod.keys`), because it's a troubleshooting detail. Say if you want only the folder shown.
- **Switch emulators:** which official sources to trust before Ryujinx or Sudachi go in the catalog. The original Ryujinx project shut down in 2024, and fork provenance needs your call.
- **Controller focus preview** in onboarding runs on the same SwiftUI focus path as the keyboard. It is not verified on a real controller.
- **Grouping badge:** on a scan tile, the badge sits over the drawn cover's title (same as Make).
- **Couch Home** doesn't show the new curated shelves yet. Only desktop Home does.

## Blocked
- **"I'm open source"** is held back. `studiojrba/nativehaul` is public, but its default branch (`production`) is old Playrite-era code with **no LICENSE** (GitHub reports none). Once MIT is on the default branch, add the line back to `OnboardingScript.welcome`.
- **Highest rated:** there is no rating field in the library, so the shelf isn't built.
- **Suggestions, Cosy, Bring a friend and Brand new on your Mac:** your 18 games have no genres, tags, release dates or covers yet. These shelves stay hidden until a metadata source (IGDB keys) fills them.
- **Pause builds:** the engine can't pause, so it stays hidden.
- **Covers research (note 3):** still owed.

## Fidelity mismatches
- **Drawn-cover sheen** is drawn round. Make's SVG gradient is stretched to the 300×420 box.
- **Drawn-cover title line height:** Make sets 0.95. SwiftUI can't tighten line spacing below the font's own, so two-line titles sit slightly looser.
- **Unselected emulator cards** keep a small shadow. Make's `bg-surface/45` has none, and the elevation tokens have no "none" level.
- **Tutorial stage bar** uses the real six stages (Found, Prepare, Verify, Patch, Finishing, Ready). Make shows five.
- **Frosted panels:** Make's backdrop-saturate can't be reproduced (as in 0.1.0).
